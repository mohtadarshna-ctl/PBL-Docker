Student Management API

A containerized FastAPI backend built for the Docker and CI/CD PBL assignment. It provides full CRUD operations for student records, structured request logging, a health check endpoint, automated route verification, and a GitHub Actions pipeline that tests and publishes the image to Docker Hub.

API Routes

When running locally or inside a container on port 8000, the following endpoints are available:

Method Path Description
GET / Returns application metadata and route directory.
GET /health Liveness probe returning {"status": "healthy"}.
GET /students Lists all students, with optional ?course= query filter.
GET /students/{id} Fetches a single student record by ID.
POST /students Creates a new student record with Pydantic validation.
PUT /students/{id} Updates an existing student record.
DELETE /students/{id} Removes a student record by ID.

Running with Docker and Docker Compose

Start the containerized API with a single command using Docker Compose:

docker compose up --build -d

Run the automated test suite against the running service:

python automationTesting.py

CI/CD Pipeline

Every push to main triggers the GitHub Actions workflow in .github/workflows/ActionsYaml.yaml. It installs dependencies, starts the FastAPI server, executes automationTesting.py across all routes, and then builds and pushes the Docker image to Docker Hub using repository secrets (DOCKERUSERNAME and DOCKERTOKEN).
